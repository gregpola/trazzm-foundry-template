# trazzm-foundry-template
    A template repository for FoundryVTT modules

### Compatibility:
  - Tested with FVTT v14 and the DND5E system 5.x

### Installation Instructions

To install a module, follow these instructions:

  1. Start FVTT and browse to the Game Modules tab in the Configuration and Setup menu
  2. Select the 'Install Module' button and enter the following URL: https://github.com/gregpola/trazzm-foundry-template/releases/latest/download/module.json
     Note: replace the repo name in the path with your repository name
  4. Click Install and wait for installation to complete
